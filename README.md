🌤️ Weather App

A simple and responsive weather application that provides current weather information and a 5-day forecast for any city.

✨ Features

- 🔍 Search weather by city
- 🌡️ Current temperature
- 🌡️ Feels-like temperature
- ☁️ Weather condition
- 💧 Humidity
- 💨 Wind speed
- ☀️ Day and 🌙 night icons
- 📅 5-day weather forecast
- 🌡️ Celsius / Fahrenheit unit toggle
- 📱 Responsive design

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- OpenWeather API
